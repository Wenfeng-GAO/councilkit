## 结构（冻结信息设计）

- 顶部「设计预览 · 全部示例数据」工具条：7 个场景快照按钮（编码中 / 独立核验 / 静默 / 断线 / 额度不足 / 候选完成 / 已准出）+「模拟新活动」「重置演示」。与产品操作分离，虚线边框+徽标区分。
- 184px 全局导航 + 232px 执行角色栏 + 弹性主区；详情用右侧 430px 抽屉按需打开（≤720px 变横滑角色选择器 + 全宽抽屉）。
- 主区顺序：上下文（目标/PR/轮次/耗时/折叠运行详情）→ 状态行 → 阶段路线（无百分比，评审与验证并行节点）→ 常驻观察栏（进程 / 日志连接 / 最近有效活动 / 最后数据分格口径分开）→ 需要处理（仅异常场景，高于时间线）→ Tabs（活动｜验收与改动）。
- 停止任务：低强调常驻按钮；历史轮隐藏、断线禁用、已准出无入口；确认弹窗（dialog）取消不改状态，确认进入「已停止（模拟）」。

## 十条演示脚本 ↔ 实现位置

1. 默认编码：`SCENES.coding`，最新「修改 session_operations.go」事件点开抽屉显示 +9−2 fake diff（含 ErrStaleGeneration 分支）。
2. 独立评审待启动：role-reviewer 无事件 → 空态提示「尚未启动 · 等候候选」，非空白。
3. 暂停跟随 + 模拟新活动×2 → 未读「有 2 条新活动 · 查看」；新事件暂存不渲染、scrollTop 不动；点查看恢复跟随归零。手动向上滚动 48px 内也会自动暂停跟随。
4. 类型=工具 + 关键词 session → 仅 session 文件/命令事件；空态提示「当前筛选无匹配」+ 清除筛选（强调不是任务没活动）。
5. 独立核验：Reviewer/Verifier 角色同时「活动中」，事件时间交错；Verifier go test 抽屉输出 ok+FAIL 混合（失败片段默认可见）。
6. 静默（心跳 8 秒前/有效活动 3 分 48 秒前分口径）；断线（保留缓存、最后同步 12:45:31、停止禁用、相对时间不走动）→「重新连接（模拟）」回编码快照。
7. 额度不足：需要处理区 + 错误片段默认可见 +「查看换席步骤」只读抽屉（停止旧执行/明确选模型/新会话/v2 同链预算继承；无清零捷径、剩余预算≠账户额度）。
8. 候选完成（待准出、远端身份未核验、无停止）→ 已准出（候选/基准 SHA+时间+5/5 证据核验面板）。
9. 验收与改动：5 项不变量四态（通过/未通过/待验证/证据不足）+ 证据来源（报告/输出摘录，非空链接）；改动汇总区分「已修改 diff」与「仅读取不显示为改动」。
10. 停止确认弹窗取消不变、确认进入模拟已停止；第 1 轮历史只读条幅+返回当前轮，历史轮无停止按钮。

## 数据一致性要点（响应评审）

- Token：运行详情显示「暂无完整用量」，并注明 500K 是上下文上限不是消耗。
- 源码派工：剩余 1 次（共 3 次 · 已用 2 次），与第 2/3 轮对应——每轮一次源码派工，第 2 轮派工已占用，只有一个计数体系。
- 场景是独立快照（INTERACTIONS 命题：静态 fake 快照演示），verify 场景中「锁顺序未通过」与已准出场景「5/5 通过」分别属于不同快照，不代表同一条剧情线。
- 历史执行结果不覆盖当前重试：第 1 轮事件带 round:1，仅历史视图可见。

## 无障碍 / 布局

- 中文系统字体；正文 14/22–16/28，元信息 13/20，code 13/22；无 12px 以下字号。
- 原生 `<dialog>` 抽屉/弹窗：Esc 关闭、focus 返还原触发按钮；角色行、事件行、Tab 均为 button 语义 + aria；`[hidden]{display:none!important}` 防止被 flex 覆盖；`prefers-reduced-motion` 关闭动画。

## Known issues / 限制（如实）

- 相对时间（「12 秒前」）为场景快照的静态标签，不实时走秒；断线场景冻结累计，避免假活跃——这是产品口径在原型上的保守落地。
- 刷新不回放「模拟/停止」等 JS 内存态（产品要求持久化恢复，原型不连存储层，属于实现范围外）。
- `screens/` 截图由 verify-prototype.mjs 用项目自带 Playwright 生成（overview / quota / mobile）。
