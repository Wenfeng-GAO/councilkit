# HTML 原型交互脚本

原型假定1440x960桌面，以静态fake快照演示真实产品的可能形态。所有数据/时间/进度均为演示，不连接线上或本机Host。

1. 默认“编码中”：首屏看到原目标、当前开发活动、上次活动、角色状态；展开最新 session_operations.go 修改，显示小段fake diff。
2. 点击左侧“独立评审”：待启动提示说明依赖候选，不用空白区域；切回“全部活动”。
3. 点击暂停跟随，再点击原型工具条“模拟新活动”两次：未读数变为2，不滚动；点击查看新活动，恢复跟随。
4. 类型选工具，输入session，只剩相关文件操作；清除筛选恢复全部。
5. 场景切到“独立核验”：看到Reviewer和Verifier同时活动；选择Verifier，展开go test命令与示例通过/错误信息。
6. 切到“静默”：保留事件，显示心跳与有效活动的不同时间。切到“断线”：显示缓存说明和重新连接；按钮恢复模拟连接，不启动任务。
7. 切到“额度不足”：说明受影响角色，查看换席步骤抽屉；只读指导，不提供伪造自动换席成功。
8. 选“候选完成”：灰色执行结束与待准出状态。选“已准出”：必要证据状态和候选身份完整。
9. 查看“验收与改动”页签，点击验收项展开证据；详情中显示日志/报告来源而不是空链接。
10. 从默认场景停止任务：先弹确认，取消不变；确认进入模拟已停止。历史轮次下没有停止动作。

演示控制条必须常驻“设计预览 / 全部为示例数据”；其场景按钮与产品UI分离。原型可提供“重置演示”，应真实恢复初始选择、抽屉、过滤器和停止状态。

视觉继承：nav #101113, roles #16171A, content #1B1D21, raised #23262C, selected #2C2924, divider #2C3037, text #E7E9EE, secondary #B2B7C2, tertiary #929AA7, brass #C9B18A, activity #8CB4E8, success #8AAE9B, error #ED969B, warning #D6B27A。没有大渐变、卡片墙、装饰图。标题26/34、正文14–16/22–28、元信息13/20、code13/22，中文正常字距。纯本地资源或内联SVG。
